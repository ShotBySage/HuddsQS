# Hudds Queer Social website

Static HTML/CSS site designed around the supplied September 2026 HQS newsletter.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload everything in this folder.
3. Open Settings → Pages.
4. Choose **Deploy from a branch**, branch **main**, folder **/**.
5. Save.

## Replace before publishing
- `assets/hqs-logo.jpg` with the original HQS logo if available.
- Replace the temporary event details in `events.html`.
- Replace placeholder social/email links in `contact.html`.
- Replace temporary photos with approved HQS photography.
- Check all accessibility information and safeguarding wording.
